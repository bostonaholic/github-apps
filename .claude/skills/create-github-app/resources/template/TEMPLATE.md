# Template app

This directory is **not an app** — it is the scaffold source bundled
with the `create-github-app` skill (`../../SKILL.md`). It mirrors the
shared structure of the real apps so a new app starts from the same
layout, and it must never be registered, deployed, or released. The
skill deletes this file from copies.

## Placeholder tokens

Exactly two, filled mechanically by the skill:

- `__APP_NAME__` — the new app's directory name (kebab-case).
- `__APP_DESCRIPTION__` — a lowercase verb phrase completing "a GitHub
  App that …", with no trailing period and no `"` or `\` (it lands
  inside a JSON string).

Everything that takes judgment instead of substitution is marked
`TODO(scaffold):`; the skill clears every marker — `app.yml` events and
permissions, `README.md` pitch and behavior sections, `AGENTS.md` module
bullets and invariants, and the `src/` module design.

Deliberately not templated (created later, per the skill's follow-ups):
`assets/` icons, a real `e2e.sh`, and `package-lock.json` (generated by
`npm install` at scaffold time).

## Keeping it in sync

When a change touches something shared across the apps — `vercel.json`,
`tsconfig.json`, `api/github/webhooks/index.js`, `package.json`
scripts/deps, the README / AGENTS.md skeletons — mirror it here.
